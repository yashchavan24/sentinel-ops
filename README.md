\# SENTINEL//OPS — Interactive Cybersecurity Field Manual 🛰️



A story-driven, 3D security operations experience built by \*\*Yash Chavan\*\*.

Showcasing practical knowledge of offensive/defensive security, kill-chain analysis, and full-stack web development.



🔗 \*\*Live Demo:\*\* \[https://yashchavan24.github.io/sentinel-ops/]



\## 🛡️ What's Inside?

\- 🌍 \*\*3D Attack Globe:\*\* Real-time-style visualization of global attack traffic (Three.js).

\- 📖 \*\*Anatomy of a Breach:\*\* Full incident timeline, T+00:00 to T+47:00 containment.

\- ⚔️ \*\*Red vs Blue:\*\* Attacker TTPs vs defender controls across the 7 phases of the kill chain.

\- 🧰 \*\*The Arsenal:\*\* 40+ real tools mapped across 8 security domains with sample commands.

\- 💻 \*\*Hackable SOC Console:\*\* Working terminal with command parsing, fake scans, and live hashing.

\- 🔐 \*\*Secure Login Demo:\*\* Client-side SHA-256 hashing, rate limiting, and lockout simulation.

\- ⚙️ \*\*Dual-Mode Backend:\*\* Zero-dependency Node.js backend that auto-injects when hosted locally, and gracefully falls back to static mode on GitHub Pages.



\## 🛠️ Tech Stack

`HTML5` `CSS3` `Vanilla JavaScript` `Three.js` `Node.js` `Web Crypto API`
